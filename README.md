# RESONANCE · 音乐可视化空间

一个可扩展的音乐可视化作品平台。首页提供精选作品、搜索、自动分类和本机收藏；点击作品进入独立效果页，可切换作品、查看使用说明、全屏或返回作品集。所有音乐和用户选择的图片都在浏览器本地处理。

当前作品：`america-states`（美国州块节奏地图）、`america-cities`（美国城市立体频谱）、`earth-spin`（点阵地球与赤道频谱）、`bay-area`（湾区科技地图）、`perth`（珀斯天际线）、`neon-spectrum`（可自定义霓虹频谱）、`space-odyssey`（星际声波公路）。

所有作品现在都使用独立的 16:9 视频预览画布，参数面板位于右侧并可折叠，播放区位于底部。播放区第一行提供选曲、播放/暂停和进度条；第二行显示文件名、预分析进度、BPM 与首拍偏移。点击“全屏画面”只将视觉预览区全屏，按 Esc 退出。预览画布里保留视觉标题等画面内容，不包含选曲、播放或设置按钮。每个作品通过 `window.resonanceScene` 暴露相同的预览接口：`canvas`、`getSize()`、`getTime()`、`resize()` 和 `renderFrame({ time, delta })`。所有作品的右侧控制区都提供视频导出；`space-odyssey` 支持逐帧 WebCodecs 编码及实时录制，其余六个作品使用浏览器实时录制，输出包含原音乐的 WebM 文件。实时录制会从歌曲开头播放并耗时约歌曲时长。

所有作品的 BPM 预分析下拉列表统一为三种方法：多频段节拍追踪、综合瞬态、低频鼓点。分析结果显示 BPM 和首拍时间偏移。能量方法统一为实时频谱、节拍能量、实时 50% + 节拍 50%、实时 50% + vizzy低频 50%、节拍 50% + vizzy低频 50%、vizzy低频、vizzy低频·分柱、vizzy低频·波纹。vizzy低频独立对整首解码音频提取 20–130 Hz 连续能量，不检测节拍或估计 BPM；播放时按音频时间插值并线性下落。`earth-spin` 赤道柱带、`space-odyssey` 左右柱带、`neon-spectrum` 环形柱带、`perth` 三条能量条及城市画面、`bay-area` 地图节点、`america-cities` 的 50 根城市柱以及 `america-states` 的 48 个州块都可选择这些方法。分析期间显示进度；未完成或失败时暂用实时能量。珀斯原有四条建筑节奏轨道保留为细分控制。

## 本地运行

需要 Node.js 22.12+，建议使用 `.nvmrc` 指定的 Node.js 24。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5188 。如果已经启动了预览服务，先停止该服务，避免端口冲突。

```sh
npm run build    # 检查湾区 TypeScript、生成湾区独立页面、构建整个平台
npm test         # 项目配置、文件完整性、音频加载检查（先运行 build）
npm run preview # 预览 dist 中的生产构建
```

GitHub Actions 会在推送到 `main` 或发起拉取请求时执行 `npm ci`、构建和测试。仓库应提交 `package-lock.json`，并排除 `node_modules`、`dist`、生成的湾区页面与本地测试音乐。

## Docker Compose 运行

在项目根目录执行：

```sh
docker compose up -d --build
```

打开 http://localhost:8032 。容器在构建时生成完整静态网站，由 Nginx 提供服务；修改源码后重新执行上述命令即可更新。停止服务：

```sh
docker compose down
```

## 目录和独立性

```text
src/projects.js                  作品注册表：标题、分类、标签、入口、封面等
src/main.js                      首页和效果页交互、hash 路由
src/style.css                    响应式界面
scenes/bay-area/                 湾区 React / TypeScript 源码副本
public/visualizers/perth/        珀斯原生 HTML / CSS / JS 及所需图片副本
public/visualizers/bay-area/     自动生成的湾区构建产物，不手工修改
public/art/                     平台封面资源
scripts/run.mjs                 本地开发和构建入口
dist/                           可发布的完整静态网站
```

所有源码、素材和运行依赖都位于本项目目录内，不通过符号链接或绝对路径引用原项目。只复制运行所需资源，未复制原目录中的音乐文件、Git 历史和日志。两个原项目保持不变。湾区卡片封面是平台专用地图示意图，效果页仍使用原始可视化引擎和地图资源。

每个效果通过同源 iframe 独立运行，保留原有音频处理和视觉引擎。珀斯设置面板超高时可滚动。切换或退出时销毁 iframe，从而结束旧页面的播放及动画。作品内的全屏按钮仅展示预览画布，按 Escape 退出。每个效果分别选择音频，平台不会跨作品传递音乐或播放进度。

收藏只保存在当前浏览器的 localStorage，不需要账户，也不跨设备同步。音频选择、分析和播放沿用原项目的本地处理方式。

## 增加作品

1. 将新作品的完整静态文件复制到 `public/visualizers/<id>/`，确保包含 `index.html`。
   新作品还需遵循 [rules.md](rules.md)：BPM 预分析、可折叠操控面板，以及选曲后自动分析与播放。
2. HTML、脚本、样式和资源之间使用相对路径。React/Vite 等项目先构建为静态文件，Vite 使用 `base: './'`；如果希望源码也由平台管理，放入 `scenes/<id>/`，并在 `scripts/run.mjs` 中增加构建步骤。
3. 在 `src/projects.js` 的 `projects` 数组中添加一项：

```js
{
  id: 'aurora',
  title: '极光 · 声音之海',
  english: 'AURORA SOUND OCEAN',
  category: '自然光影',
  location: 'IMAGINARY LANDSCAPE',
  year: '2026',
  description: '作品简介。',
  tags: ['自然光影', '粒子', '低音响应'],
  entry: 'visualizers/aurora/index.html',
  cover: 'visualizers/aurora/cover.jpg',
  accent: '#a9eace',
  featured: false,
  instructions: '选择本地音乐后自动分析 BPM 并播放。',
}
```

4. 运行 `npm run build` 和 `npm test`。新分类、作品数量、搜索、收藏以及效果页切换选项自动更新。将 `featured` 设为 `true` 可更新首页精选；只保留一个精选项目。

### america-cities · 美国城市立体频谱

新作品位于 `public/visualizers/america-cities/`。以透视投影绘制平放的美国本土地图和 50 座人口最多城市的立体频谱柱，城市人口采用美国人口普查局 2025 年建制区估计值。柱径按 50 城的对数人口归一化到 1–3，柱高由可选的通用能量方法驱动；每座城市对应从低到高的一个频段。右侧可调整地图俯角、水平朝向、频谱柱高与灵敏度；底部选曲后自动播放并预分析 BPM 与低频包络。数据来源及口径见[说明](public/visualizers/america-cities/data-source.md)。

### america-states · 美国州块节奏地图

新作品位于 `public/visualizers/america-states/`。使用与 america-cities 相同的透视投影，将本土 48 州分别绘成有厚度的立体块；每块以固定厚度整体上下升降。右侧可选择通用能量方法、跳动高度、灵敏度和地图视角。实时频谱按州从西到东映射低频到高频；默认使用节拍能量，让州块随预分析节奏一起跳动。底部选曲后自动分析 BPM 和低频包络并尝试播放，画面支持实时视频导出。州界数据来源见[说明](public/visualizers/america-states/data-source.md)。

### earth-spin · 地球自转

新作品位于 `public/visualizers/earth-spin/`。使用球面正交投影绘制点阵陆地，地球随播放时间缓慢旋转；没有国界。24 根柱沿赤道按低频到高频、再高频到低频的顺序环绕，向南北对称伸展，最长止于南北纬 30°。背景为星空。地球上增加 39 座主要城市实心灯点，位置随地球转动；对数 GDP 与所选能量各占 50%，共同控制亮度和跳动幅度。城市灯点可选择颜色，基础圆圈大小与圆圈跳动大小分别可选 1–10 px，最大半径为两项之和。城市灯光可单独选择节拍能量、实时与节拍各 50%、实时与 vizzy低频各 50%、节拍与 vizzy低频各 50%。右侧可调整旋转、点阵、星星和频谱参数；底部选曲后自动尝试播放，同时预分析 BPM 与低频包络。地理点阵来自 Natural Earth 公有领域陆地轮廓，GDP 快照年份与统计边界详见 [数据说明](public/visualizers/earth-spin/data-source.md)。

### neon-spectrum · 霓虹声浪环

该作品位于 `public/visualizers/neon-spectrum/`，视觉参考为中央霓虹频谱与城市背景。默认背景是从本项目内的 `perth-skyline` 副本复制而来的 `perth-skyline.png`，无外部目录依赖。

- 在底部播放区选择本地音频、播放、暂停及拖动进度；右侧面板调整音量和频谱响应。
- 选曲后会在浏览器本地预分析全曲基础 BPM，并在右侧面板和底部播放区显示结果。可在「分析方法」选择「综合瞬态」或「低频鼓点」，点击「重新分析 BPM」比较结果；中心圆盘和频谱轮廓会按预分析节奏轻微跳动。分析失败不影响播放，复杂节奏可能出现半速或倍速误判。
- 「中心 Logo」可用纯色圆盘或本地图片；「文字与排版」可分别设置中心文案和副标题的文字、颜色、字体、字号。
- 「城市背景」可上传本地图片、恢复默认珀斯背景、调整暗度和黑白效果。
- 各组设置可独立折叠；右上角按钮或 **H** 可收起整个工作台。「录屏纯净模式」会隐藏全部页面控件和角标，按 **H** 重新打开设置。按空格播放或暂停。

文字、颜色、字号等参数保存在当前浏览器；选取的音乐、Logo 图片与背景图片仅在当前页面使用，刷新后需要重新选取，不会上传到服务器。

### space-odyssey · 星际声波公路

该作品位于 `public/visualizers/space-odyssey/`。默认星空使用本次提供的参考图片；两侧频谱柱从笔直的透视道路边缘向内生长，随播放向道路尽头匀速移动，并从镜头下方循环补充。左侧默认使用实时频谱；右侧默认将预分析节拍冲击强度与实时频谱强度各按 50% 混合，两侧都可独立切换能量方法。分析完成前则只用实时频谱。叠加的星星从屏幕边缘向中心移动、逐渐变暗；默认 50 颗，可在面板调整为 0–200 颗。用户可替换背景、调节频谱灵敏度、道路光晕与背景暗度。选择音乐后自动尝试播放，同时在浏览器本地预分析全曲 BPM；默认「多频段节拍追踪」先从低、中、高频的能量上升检测冲击，再估计全曲 BPM 和节拍位置，只在检出冲击的位置驱动道路脉冲。也可选择「综合瞬态」或「低频鼓点」并重新分析。BPM 分析失败不影响播放。操控面板可通过按钮或 H 键折叠；窄屏默认折叠以展示完整画面。若浏览器阻止自动播放，面板会提示再次点击播放。

右侧新增「画面文字」，可设置标题、副标题、作者、位置与颜色，文字直接绘制到 canvas 中；默认关闭。新增「视频导出」，支持 720p/1080p 和 30/60 FPS，导出完整歌曲及原音乐。「自动选择」优先离线逐帧绘制，使用 WebCodecs 编码和 Mediabunny 封装，优先输出 MP4，必要时输出 WebM；浏览器没有可用的 WebCodecs 编码能力时，自动改用 MediaRecorder 实时录制 WebM，耗时约为歌曲时长。导出进度可见并可取消，音频文件始终只在本地浏览器处理。页面会显示当前的安全上下文、视频编码 API 和实时录制 API 状态；如果更新部署后仍出现旧版报错，请重新加载页面。长曲目或高分辨率导出需要较多内存，建议先用 720p/30 FPS 试用。

项目注册表是开发者维护的可信配置，不是用户提交内容的存储接口。当前没有后台上传、账户、数据库或在线编辑功能。

修改 `scenes/bay-area` 后重新启动开发命令或重新构建，以更新独立页面。首页和珀斯静态文件在开发服务器中可直接更新。

## perth-skyline 音频加载

`perth-skyline` 是珀斯项目的约定代号，对应 `public/visualizers/perth/`。页面在音频触发 `canplay` 后才启用播放；切换文件会停止旧音频并释放旧地址。加载、播放失败和播放状态显示在主控件下方，失败后可以重新选择同一文件。

本地文件先使用规范 MIME 类型加载。如果媒体元素无法识别，页面会尝试使用 Web Audio 解码，再在内存中转为 PCM WAV 播放。这个流程不上传文件，也不安装解码器；浏览器本身不支持的编码或损坏文件仍会显示失败提示。兼容解码会额外占用内存，普通可播放文件不会走该流程。

播放修复的回归检查覆盖加载就绪、解码恢复、取消旧选曲、资源释放和 WAV 编码。浏览器验证使用 MP3、M4A、PCM WAV，以及无效音频后重新选曲恢复播放。

## 发布

将完整 `dist/` 目录交给任意静态网站服务器即可。平台使用 hash 路由，可直接打开 `/#/experience/perth` 或 `/#/experience/bay-area`，无需服务器重写规则。构建使用相对路径，也支持部署在子目录。请通过 HTTP 服务访问，不要直接双击构建的 HTML 文件。

## 验证范围

构建包含湾区源码的 TypeScript 检查；自动检查覆盖注册表本地资源完整性及搜索、分类、收藏组合逻辑。音频引擎来自原项目，实际播放效果取决于浏览器支持、设备性能及用户选择的音乐。
