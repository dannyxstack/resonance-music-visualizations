# GitHub repository setup

Suggested repository name: `resonance-music-visualizations`

Description: Browser-based music visualization gallery with audio-reactive city scenes and customizable spectrum art.

Suggested topics: `music-visualization`, `music-visualizer`, `audio-reactive`, `web-audio-api`, `creative-coding`, `canvas`, `vite`, `typescript`, `react`.

After creating an empty repository on GitHub (do not add a second README or .gitignore there), connect it locally:

```sh
git remote add origin https://github.com/YOUR_USERNAME/resonance-music-visualizations.git
git push -u origin main
```

For a first public release, review the locally copied Bay Area brand images and background artwork. No license file has been chosen yet; choose one deliberately before presenting the project as open source.
