# Brand Assets

This prototype can run without official third-party logo artwork. Every company has a fallback geometric node with an initial.

For this local prototype, SVG files are placed here so the visualization can show brand-like marks in `safe-wrapper` mode. Before any public or commercial use, replace these with authorized assets and review each company's official brand guidelines.

Do not fetch or hotlink logo files automatically from random websites. Keep brand files local, versioned, and intentionally provided by the project owner.
